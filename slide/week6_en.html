HIGH-YIELD EXAM PREP

NSCA-CSCS Practice Question

Test your understanding of module key concepts.

In a battery of athletic tests, which test should be administered FIRST?
A) 300-yard shuttle run
B) 1RM Back Squat
C) Non-fatiguing tests (e.g., Vertical Jump / Height)
D) 1.5-mile run
Correct Answer: C (Non-fatiguing tests)
Explanation: Non-fatiguing tests (e.g., resting heart rate, skinfolds, vertical jump) must precede high-fatigue strength, anaerobic, or aerobic capacity tests.
